# N5–N2 语法书配套例句点读与 MP3 生成包

## 当前交付是什么

本包包含点读网页、全书例句数据、MP3 生成程序；**不含已经录制好的 MP3**。

数据对应现有的《日语语法合集 N5–N2：注音例句版》PDF：622 条、1,244 个例句。每条保留原书编号、页码、语法标题、中文意思、接续、辨析、词汇及两个双语例句。N5 / N4 / N3 / N2 分别为 87 / 129 / 183 / 223 条。

本次实现的朗读范围是**日语例句及可选中文译文**，不是整本书的中文语法讲解录音。语法说明与词汇在网页中可阅读；没有把混合语言的书面符号机械地送入配音引擎。本次也未重新审核原书全部分级、语法表述与例句的语言准确性。

制作环境无法连接在线语音服务，尚未获得真实的日语合成音频。程序的语法、数据完整性与离线音频拼接功能可以检查，但无法据此保证你的网络环境下一定合成成功，也不能宣称已经试听核对了全部读音。

## 最简单的方式：打开点读网页

将 `Japanese_Grammar_Audio_Reader.html` 保存到电脑，用浏览器打开，不需要安装 Python。网页本身是单个文件，不依赖其他数据文件。

选择一个日语声音后，点击“播放本条”。默认流程是：

> 日语原句 → 中文译文 → 日语慢读 → 留白 4 秒 → 日语原句。

可以关闭中文、调语速、调留白、隐藏假名或译文、按等级筛选、搜索编号、从当前条目开始连续播放。单句按钮只读当前日语句子。

网页使用浏览器/设备提供的 Web Speech 语音接口，并不内置声音模型。可用声音、是否联网、语调和速度因设备而异。没有日语声音时，页面会提示，不会用英语或中文声音代读。可先点击“刷新声音列表”；仍没有声音，需要配置设备的日语语音或改用能够提供日语声音的浏览器。

默认去掉括号注音后朗读原句。“按书中假名送读”会把汉字改为书内假名读音，可辅助修正同形异音词，但可能改变语调。两种方式都不等于完成了发音审校。

网页不申请麦克风权限。它不主动上传 PDF；但选择网络声音时，被朗读的文字可能由浏览器发送给语音服务提供方。不能保证所有设备离线可用。关闭网页、休眠或浏览器限制可能中断连续播放。

**此网页仅点读，不保存或导出 MP3。**

## 生成可保存的 MP3

需要 Python 3.10 或更高版本，以及能访问在线语音服务的网络。程序使用 `edge-tts` 合成语音，再用 FFmpeg 拼接与编码；缺少 FFmpeg 时使用 `imageio-ffmpeg` 提供的程序。在线服务可能变更、限流或不可用。

在此目录中打开终端，运行：

```bash
python -m pip install -r requirements.txt
python generate_audio.py
```

默认**只生成 N5-001 到 N5-003**，便于先试听；不会一运行就批量合成整本书。Windows 用户也可以双击 `start_sample.bat`，它会安装依赖并尝试生成这三条。系统的 Python 命令必须已经配置好。

成功后，文件位于：

```text
audio_output/
  study_bilingual/
    N5/
      N5-001.mp3
      N5-001.srt
      N5-001.json
      ...
```

每条生成一个 MP3、一份分段字幕和一份含原书页码/声音/时长的记录。字幕按合成片段的实际时长拼接，不是逐字强制对齐字幕。

### 试听后再批量生成

生成 N5 全部条目：

```bash
python generate_audio.py --level N5 --all-entries
```

生成任意一段，例如 N4 第 1–10 条：

```bash
python generate_audio.py --level N4 --start 1 --end 10
```

生成全书的例句跟读版：

```bash
python generate_audio.py --level ALL --all-entries
```

生成只含日语、每句一次并留白的复习版：

```bash
python generate_audio.py --level ALL --all-entries --mode review --no-chinese
```

更改留白，或按书中假名送读：

```bash
python generate_audio.py --gap 6 --use-readings
```

声音默认从服务返回的可用名单中选择。查询可用中日文声音：

```bash
python generate_audio.py --list-voices
```

指定其中一个日语声音：

```bash
python generate_audio.py --ja-voice "从列表复制日语声音名称"
```

同一配置已有成功文件时会跳过；已合成片段有缓存。网络中断后再次运行相同命令可利用缓存续作。改变声音、内容或留白会重新构建相关轨道。全书模式请求量较大，建议先分级生成；不要开启多份程序同时向在线服务大量请求。

`edge-tts` 项目提供无独立 API 密钥的使用方式，但它是第三方客户端，不是服务商对免费额度、稳定性或长期使用的保证。程序不会请求你的账户密码或银行卡；使用者仍需遵守服务条款。不要在聊天中发送 API 密钥。

## 不联网，仅检查脚本

```bash
python generate_audio.py --level ALL --all-entries --dry-run
```

此命令不需要先安装依赖，只把所选范围的播读顺序导出为 JSON；**不生成音频**。

## 质量与范围

- 内容编号和例句数量已对照 PDF 进行结构检查。
- 包含的音频程序用于合成发音，不是真人录音。网络语音效果在制作环境中未得到成功试听验证。
- 日语的同形异音词、助词读法、句子重音等仍需试听核对；不要把默认声音等同于经日语教师逐句监修的读音。
- “完整讲解版”还需要把中文接续说明、注意事项与生词解释改写成适合听的分语言稿件，然后逐条合成和检查。本包并未把这部分标为已完成。
