# 言葉 · Kotoba Study

围绕教材学习日语：阅读语法、听读例句、收藏生词，再用间隔复习把内容记住。

支持电脑、iPhone / iPad 的响应式 PWA。已有 **622 条 N5–N2 语法、1,244 个双语例句**，
完整保留原教材的编号、顺序、页码和文字。

## 第一次使用

1. 打开部署的网站，点击「登录并同步」。官方部署使用 ChatGPT 登录。
2. 在「语法库」选择正在学习的内容，点击「加入复习」。
3. 点击例句下方的词语收藏到「生词本」；收藏不会自动产生背诵任务。
4. 在「复习」先回忆，再翻面，并按真实情况选择忘记 / 费力 / 记得 / 轻松。
5. 在另一台设备用同一账号登录即可继续。断网更改会暂存在本机，联网后自动上传。
6. 定期在「我的」导出备份。iPhone / iPad 可从 Safari 分享菜单添加到主屏幕。

登录使用你原来登录 ChatGPT 的方式。例如原来使用 Google，就在官方登录页选择「使用 Google 账户继续」。
如果卡在 `auth.openai.com`，这是平台登录流程；应用无法读取或处理你的密码。
若已经返回学习页面但加载超时，可点击「重新加载」。浏览器存储不可用时会显示提示，不会因此推翻服务器已确认的登录身份。

## 第一版功能

- 完整语法库：等级、搜索、收藏、注音与翻译开关、原书 PDF 定位、个人笔记。
- 点读：中日文分别选声，单句 / 本条 / 连续播放，常速、慢读、留白、暂停和停止。
- 音色比较：同句试听 Nanami 女声 / Keita 男声，语法库优先播放已生成 MP3，并标明声音来源。
- 生词本：写法、读音、原文释义与来源例句；外来词原语言信息保留。
- FSRS：固定 `ts-fsrs@5.4.2`，目标保留率 0.9，关闭随机扰动；默认每天最多开始 10 张新卡。
- 120 分钟每日计划与完成标记、学习日记、七天复习记录。
- 云同步、按账号隔离的离线缓存、备份合并恢复。
- N5-001～003 三条真实 MP3 / SRT / 元数据，可下载试听。
- 旧版单文件点读页保留在 `/reader.html`。

计划日期以东京时区计算。每日完成分钟是计划完成量，不是实测学习时长。
当前为理解卡与生词卡；审核后的填空题、听力卡、录音、完整 N1 内容和模拟考试尚未加入。
当前教材不是 N2 的完整词汇、阅读和听力课程，也不提供考试通过率预测。

## 本地运行

需要 Node.js 22.13+（本次使用 24.19.0）与 npm。

```sh
npm ci
npm run db:generate  # 首次克隆已有迁移时可以跳过
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_breezy_golden_guardian.sql
npm run dev
```

打开终端打印的 localhost 地址。本地开发登录仅用于本机测试，使用模拟账号，不会登录真实 ChatGPT 账户。
迁移只在本地首次初始化时执行一次；生产部署由平台应用迁移，不要重复执行或改写已应用迁移。

```sh
npm test
npm run typecheck
node tests/sync-api.mjs  # 先启动本地 dev 与数据库
```

## 部署与同步

前端：React / TypeScript / Vinext；持久化：Cloudflare D1；认证：Sites 的 ChatGPT 登录。
`.openai/hosting.json` 只保存逻辑绑定与 Site 标识，不含密钥。
Fork 后需要注册自己的 Site 并替换 `project_id`，不能复用维护者的 Site。

这不是直接放到 GitHub Pages 就能完整运行的纯静态项目：自动同步需要后端数据库和可信认证网关。
若迁移到其他托管平台，须替换认证适配层，并确保客户端不能伪造 `oai-authenticated-user-*` 头；
不要把直接信任这些头的 Worker 暴露到缺少认证网关的公网。
官方在线实例默认仅维护者可访问；代码开源不等于开放个人实例或私人学习记录。

## 数据与同步设计

教材唯一来源：`public/data/grammar.json`。修改教材后运行 `npm run content:sync`，同步生成便携 HTML 的内嵌副本。
原 JSON 与 PDF 从原项目按字节保留，词条仅作为派生视图读取，不改写教材原文。
生词例句按原条目内的写法、对应注音、词边界与有限活用关联；无法确定时显示待确认，不再任意显示第一句。
当前 2,496 个生词记录中 2,366 个已关联，130 个待确认。这是显示关联检查，不代表全量语义审校。

- 语法用原编号；词条当前以 `word:<语法编号>:<原词项序号>` 标识。订正时不能重排词项；未来改动需显式迁移 ID。
- 追加事件表按服务器确认顺序重放，写入 ID 幂等，服务器从认证上下文取得所有者。
- 收藏/取消、设置、学习位置使用最后确认事件；删除是状态事件，不抹去历史。
- 笔记带基础版本，冲突保留两个版本；再次保存合并内容可解决冲突。
- 同一张卡片的并发离线评分只接受匹配当前版本的链，冲突评分保留为历史，避免重复推进。
- IndexedDB 是离线缓存和待发队列；D1 是账号的权威记录。退出登录隐藏本机账号数据，待发队列保留在原账号下，重新登录同一账号后继续同步。
- Service Worker 只缓存无个人信息的应用外壳、教材和静态资源，不缓存登录页或 API 响应。

## 音频

样例均已通过解码与字幕对应检查，**未试听**，不能宣称读音已正确。
前三条双语跟读整轨详见 [音频检查报告](docs-audio-verification.md)。
另有 N5-001～003、N4-001～003 的 12 句原文 × 两种日语声音，共 24 个独立 MP3 与 SRT，见 [音色样例报告](docs-voice-samples-verification.md)。
打开「我的 → 打开音色试听」，或者语法库「比较音色」，可以试听并保存偏好，设置随账号同步。
当前默认 Nanami；覆盖的例句自动播放文件，未覆盖的 616 条、单词及中文译文仍使用浏览器语音，并显示来源。
开启「按书中假名送读」时使用浏览器声音；试听对比固定原句、常速。
文件加载失败会明确提示，不会悄悄切换声音。音频目前需联网播放，也可逐句下载；尚无全书离线音频包。
慢读使用保留音高的播放速度调整。原版 `/reader.html` 保持原有浏览器朗读功能。
浏览器朗读由设备提供，网络声音可能发送朗读文字到语音服务；缺少日语声音会明确报错。
已有 Python 生成器保存在 `legacy/`，运行方法见该目录说明。新增语音服务、完整讲解配音和全书合成是后续阶段。
本轮样例生成器为 `scripts/generate_voice_samples.py`，默认仅制作这六条，支持缓存重试及 `--verify-only` 离线验收。
